## 1. Policy proposed for the whole set (in ADR-0026)
Exact pins in `package.json` (no ranges) · each release ≥ 14 days old at review time (all pins are) · committed `pnpm-lock.yaml` with integrity hashes · installs with lifecycle scripts disabled (`--ignore-scripts`/pnpm default build-script allow-list), except a named, pinned Playwright browser download in CI · **Node ≥ 22.22.2** recorded in `engines` and CI (`react-router` ≥ 22.22.0, `jsdom` ^22.22.2) · `pnpm audit` and an OSV check as CI gates (D-26) · CycloneDX SBOM from the lockfile in CI (`pnpm sbom` verified available in the pinned pnpm) · upgrades only by PR with the same evidence · no dependency may add runtime network calls, `eval`/`new Function`, browser storage or telemetry.
